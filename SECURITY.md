## Reporting a Vulnerability

We take the security of this project seriously. 

If you discover a security vulnerability, please do NOT report it by opening a public issue. 
Instead, please report it via the contact form at: **https://shereef.net/contact**

We will acknowledge your report and keep you informed of our progress towards a fix and an announcement. We adhere to responsible disclosure principles and ask that you give us time to patch the issue before making it public.
