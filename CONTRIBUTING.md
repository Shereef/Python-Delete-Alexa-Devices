# Contributing to Python-Delete-Alexa-Devices

First off, thank you for considering contributing to this project. It's people like you that make this tool great.

## Code of Conduct

By participating in this project, you are expected to uphold our [Code of Conduct](CODE_OF_CONDUCT.md).

## Getting Started

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally: `git clone https://github.com/your-username/Python-Delete-Alexa-Devices.git`
3. **Set up the environment**: This project uses `uv` or `pip` with `pre-commit`.
   ```bash
   pip install -r requirements.txt
   pre-commit install
   ```

## Development Workflow

1. Create a branch for your feature or bug fix:
   ```bash
   git checkout -b my-new-feature
   ```
2. Make your changes, ensuring that the code adheres to the existing style. We use `ruff` for linting and formatting.
3. Commit your changes. Be sure to write clear and concise commit messages.
4. Push to your fork and submit a Pull Request.

## Pull Request Guidelines

- Ensure your code passes all checks (`ruff`, etc.).
- Update documentation (like `README.md`) if you are introducing new features or altering existing behavior.
- Use the provided PR template.

## Issues and Bug Reports

We use GitHub Issues to track public bugs and requests. Please see our Issue Templates for bug reports and feature requests.

If you find a security vulnerability, do NOT open an issue. Please refer to our [Security Policy](SECURITY.md).
